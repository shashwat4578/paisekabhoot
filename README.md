# PaisekaBhoot - Mutual Fund Portfolio Management

Professional-grade automated mutual fund NAV pipeline and portfolio tracker.

## Features
- **Daily Automated Updates**: Historical and live NAV data fetched via AMFI.
- **Performance Analytics**: 1D to 5Y absolute and CAGR returns.
- **Fund Explorer**: Search over 10,000+ funds with real-time ranking.
- **Portfolio Tracking**: Goal tagging, XIRR calculation, and Tax summaries.

## Tech Stack
- **Frontend**: React + Vite
- **Backend**: Supabase (PostgreSQL)
- **Pipeline**: Python + Pandas + GitHub Actions
